# Skills in Aldo

A skill is how you want a kind of task done: the steps, what to do and what to avoid, the feedback you've given. **Settings → Skills** holds yours. They're saved to your account, and every cloud agent in every thread has them: Claude, Codex, OpenCode and Grok.

Each agent sees every skill's name and what it's for, and reads the rest only when a task matches. A skill for podcast clips, say, is followed whenever an agent makes clips, in any thread, without you pasting your feedback again.

## Asking an agent to make one

Tell an agent in any thread, for example "Make a skill for podcast clips with this feedback". It writes the skill for an agent that hasn't seen your conversation and saves it to your account, where it shows up in Settings → Skills.

To change one, ask any agent to add to it ("Add to the podcast clips skill: never cut mid-laugh"). When you give feedback on work a skill covered, the agent offers to add it. Agents never put a value from your vault in a skill.

## Writing one yourself

Choose **New skill**:

- **Name**: lowercase letters, digits and hyphens, such as `podcast-clips`.
- **When to use it**: what the skill is for, in a sentence or two. Agents decide from this alone whether to read the rest, so name the tasks it covers ("Use when making clips, shorts or reels from a podcast").
- **Instructions**: the skill itself, in Markdown.

**Open** a skill to edit or remove it. If an agent saves a new version while you have it open, **Save** and **Remove** show you what's saved now instead of overwriting it. Save or remove again to go ahead.

## When changes apply

Threads that are running get a change at once. The others get it the next time their machine starts or wakes, and new threads always start with the latest.

You can keep up to 50 skills.
