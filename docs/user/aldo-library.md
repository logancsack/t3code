# The Library in Aldo

What your agents make for you (sheets, documents, decks, PDFs, images, pages) and what they share by link, in one place: beside each thread, and for all your threads in Settings.

## In a thread

In a General thread, or one in an Aldo project, open **Library** in the panel beside the thread: from the panel's launcher (or press **L** while it shows), or from **+** beside the panel's tabs.

It lists what the thread made, newest first, under **Today**, **This week** and **Older**. A file the agent changed in several turns shows once, at its latest change; scripts and other working files stay out of the list. Tap a file to open it beside the thread. **Share** asks the agent to share it by link.

A file the agent shared also says who can open it:

- **Public link**: anyone with the link.
- **Only you**: only you, signed in to Aldo.

**Copy link** copies the link, **Open link** opens it in a new tab, and **Stop sharing** turns it off (see below).

When the list is empty, nothing has been made or shared in the thread yet. It fills in as the agent works.

## Shared files

**Settings → Shared files** lists everything your agents shared by link, from every thread, grouped the same way, with each one's type, size and how many times it was opened. **Settings → Integrations** links to it too, under **Files your agents shared**.

When your Aldo says where each file came from, buttons at the top show just one project's, or just General's, and each row names the place it came from. The page lists the 200 most recent.

## Stop sharing

**Stop sharing** asks once, then turns the link off at once: anyone who opens it from then on, you included, finds nothing there. Aldo deletes its shared copy. The agent's own file stays where it was, so you can still open it in the thread, and ask the agent to share it again for a new link.
